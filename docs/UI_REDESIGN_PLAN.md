# 界面重设计方案（UI_REDESIGN_PLAN）v1.0 · 大厂三角色评审收敛

> 2026-10-02 · 评审角色：大厂产品总监 / 高级产品经理 / 资深 UI 设计师（均直读代码）。用户判决："很不满意、太土"。
> 已即时实施：v5.0 视觉层（Vercel 系近黑实色令牌、删 13 处渐变/7 处辉光/3 层环境光、统一三橙两红为单点缀色、修复 11 个丢失 CSS 类、版本号统一、明文口令遮蔽）。

## 一、评审共识判决
- 现状 = "AI 产品默认皮肤"（玻璃拟态+渐变+辉光=装修不是设计）；里子（可审计/诚实对账）是 2026 的，面子配不上。
- 最大硬伤不是配色，是 IA：默认落地页竟是使用说明；双导航打架；炉次被切成五页游；没有全局态势层。

## 二、目标 IA（炉次为中心，状态驱动）
00 态势墙（所有炉卡片墙：阶段色/距 Tc 裕度/告警数，异常置顶）→ 01 当前炉次驾驶舱（开吹+吹炼合并为一条时间流，时间轴即导航）→ 收炉自动跳 03 结账页（三连✓+半钢交接单+记台账大按钮）→ 复盘/治理下沉管理员抽屉。使用说明降级为右上角"？"。

## 三、现场话术替换表（15 条，已核准待实施）
SIMULATION→演示模式(红字水印)｜PERCEIVE/JUDGE/PLAN/ACT→它在看/它觉得/它打算/它在做｜SSE 同化中→正在吃数据｜外推中→副枪 X 秒没来，机器在猜｜距 Tc 裕度→离"碳抢钒"红线还有几度｜补吹线→钒没吹够要补一枪的线｜融合方案→两套老师傅经验合开的加料单｜case_2777/15000→专家A算法/文献算法｜session_id→今天第 N 炉｜采纳(模拟执行)→按它说的干(我确认)｜确认入台账→记入本班台账｜口径冲突→两本账对不上｜覆盖率→十炉里有几炉说准了｜learned_entries→已记 N 炉｜F/S/M/CF/σ/KF/ODE 编号全部撤出页面。

## 四、交互规范
- 时间轴=高德导航隐喻：横向路线、当前段高亮、副枪画路口、提前 30 秒提示"快进收钒期，准备降枪位 1000"、顶部大倒计时"距提枪 X 分 X 秒"。
- 智能体=微信气泡一句人话（"火焰温度比化验单高 18℃，建议多加 300kg 球团"），置信用红黄绿灯不用小数，周期号/ms 隐藏。
- 建议卡=外卖抢单式大字动作+底部作废倒计时条；否决只留"干不了"按钮+原因点选。
- 告警=分级+ACK+静音+历史，禁永久闪烁。

## 五、已核准未实施的 P1 清单（下一迭代）
1. 态势墙+炉次列表（全局层）；2. 开吹+吹炼合并时间流；3. 收炉自动跳结账页+提醒；4. 化验单 7 格手敲改单据卡确认；5. 大数砍到 3 个+温度仪表盘化；6. 话术替换表全量执行；7. 演示/治理/字典收管理员抽屉；8. 图表 uPlot/ECharts 化（十字线/hover/量程自适应）；9. 复盘页炉次列表选择替代粘 ID；10. 红线做成带 build 号 CI 徽章。
