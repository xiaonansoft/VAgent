# 工作台 v7 整舱重写规格（UI_V7_SPEC）· 执行版

> 2026-10-02 · 用户连续三次判定"不好看、不好用"。结论：放弃对 v6 的增量修补，**清仓重写单一文件 `webapp/VERO_WORKBENCH.html`**（后端 API 不动）。本规格即施工图，执行时逐条对照，不留旧代码。

## 布局：单屏三区驾驶舱（不滚动，1440×900 优先）

```

│ VERO·融合方案 | 炉号 | 阶段徽章 | 大倒计时"距提枪 X:XX" | 演示模式 | ？│
├─左栏(200px)────────┬─中央主区───────────────┬─右栏(320px)──┤
│ 炼钢时间轴(竖向)    │ 态势行(在吹N·告警M)      │ 智能体        │
```

## 硬规则（评审教训全部内建）
1. **零渐变/零发光/零玻璃**——v5 令牌（bg0 #0A0B0D 三阶近黑 + 单点缀 #E05D2B + GitHub 系语义色）。
2. **五档字阶** 11/12/13/16/32；大数 32~64px mono tabular；卡标题 13px/500；正文 13px。
3. **圆角三档** 6/10/12；全部 1px 实线边框 var(--line)；hover 只变边框色。
4. **图标**：内联 SVG stroke 1.75，统一 24 viewBox（lucide 路径手选 ~10 枚）。
5. **中文优先**：全部界面文案中文（保留英文仅限代号列），英文 ID 进 `?` 抽屉。
6. **状态色即语义**：正常=白/灰，注意=warn 琥珀，危险=danger 红，好=ok 绿——只染数字与细条，不染整卡。
7. **密度**：卡内边距 14px，卡间距 12px，表格行高 36px——信息密度对标 Datadog。

## 功能映射（v6 全保留，无功能删减）
- 态势墙 → 顶栏"炉号"下拉 + 左栏顶部炉卡（简化为选择器+迷你卡）；全局墙后续加。
- 开吹（化验单据卡→融合方案→指令单）= 中央区"未开吹态"置换内容；开吹后同位置置换为驾驶舱。
- 吹炼（时间轴/大数/建议/留痕/智能体）= 三区分布如上；建议卡只有 1 张主位。
- 收炉 → 中央置换结账卡（三✓矩阵+半钢交接+记台账）+ 顶栏倒计时归零。
- 复盘/治理/使用说明 → 底栏与"？"抽屉进入（次级页签保留但不在一级导航）。
- 演示控件（场景/倍速）→ 仅演示模式显示，收进中央区右上角"演示"小抽屉。

## 交互细节
- 大倒计时 = 顶栏中央 20px mono，<60s 变 danger。
- 温度仪表盘：半环 SVG，1350~1420 绿弧、出窗红/蓝，指针=当前估计，中心大字。
- 时间轴竖列：SOP 四段各 64px 高，当前段左侧 3px accent 竖条 + 剩余秒数；副枪①②菱标；事件钉右侧圆点（橙=建议/绿=采纳/红=告警）。
- hover 数字 = 字典浮层（沿用 data-dict 机制）。
- 声音：告警时短促 beep（WebAudio, 可静音）。
