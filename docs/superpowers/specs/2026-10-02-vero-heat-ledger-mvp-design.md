## 1. 目标与成功标准

**用户**：工艺工程师 / 技术科（主），车间主任（看日报），炉长（看自己班组的对账，不排名）。

**一句话**：工艺师导入一段时间的逐炉台账，系统逐炉、逐渣批把钒和热量算清，指出"钒丢在哪、哪几炉/哪几批异常、为什么"，并审计规程查表与机理是否打架。

**MVP 验收（合成数据上，全部自动化测试）**：

| # | 判据 | 门槛 |
|---|---|---|
| AC-1 | 合成数据中埋入的四类异常（见 §4.3），归因主因命中 | 召回 ≥ 80% |
| AC-2 | 账本自洽：分摊到炉次的流失之和 = 渣批差额；炉次→渣批→日→数据集四级漏斗逐级加总一致（引擎内烟尘钒为差额项，逐炉守恒是恒等式，不作为验收） | 相对误差 ≤ 1e-6 |
| AC-3 | 规程审计自动报出 B 厂查表在 Si 0.20%→0.22% 处的折算跳变 | 必报 |
| AC-4 | 合成数据导出为模板 CSV/XLSX 再导入，分析结果与直接分析一致 | 逐字段一致 |
| AC-5 | A 厂引擎黄金用例零漂移；安全扫描四项通过 | 75/75、4/4 |
| AC-6 | 调查智能体主因命中（剧本模式，评测集 §11.5） | top-1 ≥ 80% |
| AC-7 | 调查输出数字引用合规；无来源数字 | 100%；0 |
| AC-8 | 负样本（正常时段）误报 | ≤ 10% |
| AC-9 | 断开 LLM 后 AC-6~AC-8 全部通过 | 必须 |

**真实数据前提（不在本期软件范围，但决定下一步）**：B 厂 3~6 个月逐炉台账。拿到后只换文件，不改代码。

## 2. 范围

**在**：台账导入（模板 + 校验 + 适用范围检查）、合成逐炉数据生成器、逐炉/渣批钒账本核算、异常归因卡、规程审计（A 机理 × B 查表）、日报导出、工艺师单页工作台。

另含**异常调查智能体**（§11）：自然语言提问或点选异常对象 → 封闭假设集逐条用确定性工具验证 → 带引用的结论。

**不在**：吹炼中实时推荐、半钢炼钢段模型、多智能体 / A2A、长期记忆、LLM 写代码做分析、开放式检索、标准合规 MCP 服务（本期只做注册表双导出）、图数据库/OWL、任何控制写入、个人/班组排名与考核打分、修改现有 `blow` 会话与 `initial_charge` 引擎。

### 4.2 渣批表（模板 `batches`）

`batch_id, slag_t, V2O5, TFe, CaO, SiO2, MFe`（% 口径为粗渣装车样）；可选冷料批表 `coolant_lots: lot_id, CaO`。

校验：必填、单位范围（如 Si 0~1、iron_T 1150~1450）、炉号唯一、渣批引用完整。**适用范围检查**：每炉对照主张库中的 envelope（Si/温度/冷料品种），越界炉次照常核算但标 `out_of_envelope`，不进入统计效应估计。

### 4.3 合成数据生成器

- 规模可配（默认 90 天 × 24 炉/天 ≈ 2160 炉），种子确定性；渣批按 2~3 炉一批。
- 输入分布按 B 厂规程统计特征：Si 主体 0.10~0.40（含 Si>0.25 段）、V 0.26~0.31、iron_T 1250~1340。
- 冷料按 B 厂 p21 查表 + 操作噪声给定；半钢温度用 A 厂引擎对 `semi_steel.temp` 二分求解使热平衡余量为 0，再加测量噪声 → 热量自洽。
- 渣批实收 = 预测入渣 V₂O₅ × (1 − 流失率)，基础流失率 + 噪声。
- **埋入四类异常**（标签只写入 ground truth，分析代码不可读）：
  1. **下渣流失**：某段时期出钢口老化，`tap_s` 逐步缩短到 < 210 s，流失率上升；
  2. **一罐到底**：某段 `one_ladle=true`，iron_T +20~30℃，渣 CaO 上升（高炉渣带入）；
  3. **冷料 CaO 超标**：某冷料批 CaO 高，引用该批的渣批 CaO 上升、品位下降；
  4. **供氧不足**：某段 `oxygen_s` 低于规程下限，semi_V 偏高（提钒不彻底）。
- 输出带 `source: synthetic`，界面与报告全程显示"合成数据"水印。

## 5. 核算（engine.py）

**逐炉**：用实测铁水成分/温度、实加冷料（映射：球返→pellet、弃渣球→waste_slag_ball、铁块→pig_iron_weight、钒渣钢→metal_fe 口径——**近似映射，登记为假设 H-1**）、实测半钢 C/V/终点温度，`corrected=True` 运行 A 厂引擎，取：

- `heat_residual_kJ`：热平衡余量（正 = 模型认为应更热 → 冷料偏少或测温偏低；负反之），换算等效温差 ℃；
- `v_in`、`v_oxidized = v_in_iron − v_out_semi`、`v2o5_to_slag_pred`（kg）、`slag_mass_pred`；
- 钒平衡各项（原样保留供明细展示）。

**渣批**：`v2o5_pred = Σ 成员炉 v2o5_to_slag_pred`；`v2o5_actual = slag_t × V2O5%`；`recovery_gap = 1 − actual/pred`；`grade_pred = Σv2o5_pred / Σslag_mass_pred`，与实测品位对比。

**钒漏斗（数据集/日/班）**：铁水带入 → 已氧化 → 预测入渣 → 渣批实收；差额 = 流失，按成员炉预测贡献比例分摊到炉次。

**指标口径**：钒氧化率 = v_oxidized / v_in_iron；钒回收率 = v2o5_actual 折 V / v_in_total。口径写入字段字典，界面可查。

## 6. 归因（attribution.py）

**两层**：

1. **规则标记**（确定性，每条规则引用主张 ID 与页码）：
   - `tap_s < 210`（3.5 min）→ 下渣风险；
   - `one_ladle` 或 iron_T 显著高于批次均值 → 一罐到底/热量偏高；
   - 冷料批 CaO > 主张阈值（1.2% 口径待厂确认，登记 H-2）→ 冷料杂质；
   - `oxygen_s` < 规程下限（一般 >310 s、出渣炉次 >320 s、Si≥0.22% >330 s）→ 供氧不足；
   - Si > 0.25 → 高硅；实加冷料偏离查表推荐 > 阈值 → 配料偏差；`|heat_residual| ` 等效 > 15℃ → 热量不自洽（测温/冷料实吊量可疑）。
2. **效应估计**：对渣批层 `recovery_gap`、品位残差、CaO，对炉次层 semi_V，用最小二乘回归到上述因素的批次均值/占比上，得到每个因素的效应量与置信区间；对每个异常对象，按"规则命中 × 效应量"排序出主因、次因。

**异常判定**：残差超过数据集稳健 σ（MAD）2.5 倍的渣批/炉次进入异常列表。

**归因卡**：对象（渣批/炉次）、现象（数字 vs 基线）、主因与次因（效应量、命中规则、主张出处）、证据炉次清单、建议核查项（只建议核查，不下结论定责）、数据质量标注（越界、缺省、热量不自洽）。

## 7. 规程审计（audit.py）

- 网格：Si ∈ B 厂 p21 表各行 × iron_T ∈ {1260, 1280, 1300, 1320, 1340}，装入 80 t。
- B 口径：查表球返 kg/t + 温度修正 1.5 kg/t/10℃ + 铁块、钒渣钢按当量（1 t 球返 = 6 t 铁块 = 1.7 t 钒渣钢）折算为球返当量 kg/t。
- A 口径：A 厂引擎 `pellet=None` 自动求解所需球团 kg/t（其余冷料 0），半钢目标取主张中的终点温度中值。
- 输出：两口径的 ∂/∂Si、∂/∂T 斜率与截距差；B 当量序列单调性检查与跳变点；表注规则与当量的自洽检查（如"无铁块多加球返 0.5 t"vs 当量折算）；每项生成冲突条目 `{id, claim_a, claim_b, 差值, 说明, status=open}`。
- 审计结论只陈述差异与证据，**不改任何参数**。

## 10. 工作台（webapp/VERO_LEDGER.html）

单页，无构建，原生 JS + 纯 SVG（不引入 d3/CDN，完全离线），后端 `/ui` 同源托管，`/ledger` 重定向。

### 10.1 体验原则

"眼前一亮"按强度：**顿悟感**（第一次看清钒丢在哪、丢了几吨）> **信任感**（每个数字点开有出处）> **省事感**（一键上会）> **智能感**（它先列假设再逐条排除）> 视觉。视觉只做放大器。

禁区：深色科技大屏/3D/粒子、假打字动画与长时间"思考中"、无依据的置信度百分比、处方式建议（只允许"建议核查"）、班组排名、伪精度（小数位按字段固定）、隐藏"未解释"损失。动效 ≤ 200 ms，只引导视线；桑基入场一次 600 ms。

### 10.2 布局：发现为中心的三栏（1440×900 基准）

### 10.3 五个关键时刻（按优先级）

1. **开场 30 秒（P0）**：生成/导入后进度依次走"校验→逐炉核算→渣批汇总→归因"，发现卡逐张落入左栏，用户未提问即得三个最大发现。
2. **可下钻钒流桑基（P0）**：前段画引擎**预测**去向——铁水带入 → 已氧化（分出半钢残钒）→ 预测入渣（分出铁珠、喷溅、烟尘）；后段画**实测差额**"预测入渣 − 渣批实收"，按归因因素（下渣 / 一罐到底 / 冷料 CaO / 供氧不足 / 配料偏差）拆分，残差如实标"未解释"。全图守恒（与 AC-2 同源）。点支流 → 过滤发现流 + 下钻渣批/炉次 + 打开证据抽屉。
3. **点数字即溯源（P0）**：全站数字带引用角标，悬停高亮来源，点击打开抽屉；无引用数字显示为灰色斜体"未核实"。
4. **规程审计对照（P0）**：A 机理曲线与 B 查表当量曲线叠图，Si 0.20→0.22 跳变红圈，旁置 p21 原文与引擎值，状态"待裁决"。
5. **调查过程可见 + 一键日报（P1）**：提问后右栏步骤时间线逐步展开（SSE）；日报为一页 A4（三个发现 + 桑基缩略图 + 待核查清单，数字带脚注），可打印/导出。

**揭晓答案开关**（仅合成数据集）：叠加 ground truth，显示"未看答案，命中 n/4"（AC-1 可视化）。

## 11. 异常调查智能体（ledger/agent/）

### 11.1 工具（只读，每次调用返回 `call_id`，如 T07）

| 工具 | 输入 | 输出 |
|---|---|---|
| `resolve_scope` | 日期/班次/对象 ID | 目标集合 + 基线集合 |
| `ledger_query` | scope, metric, group_by | 指标表 |
| `slice_compare` | 暴露条件, 对照条件, metric | 差值、CI、n |
| `regress` | target, factors, scope | 效应量、CI |
| `rule_hits` | scope | 命中规则、主张 ID、页码 |
| `whatif_heat` | heat_id, overrides | 引擎重算热余量与钒平衡 |
| `claim_lookup` | claim_id / topic | 主张原文与出处 |
| `data_quality` | scope | 越界/缺省/热不自洽 |
| `judge_hypothesis` | 证据 call_id 列表 | supported / refuted / insufficient |

工具注册表单一来源，可同时导出 OpenAI tools 描述与 MCP `tools/list`（标准合规 MCP 服务列下期）。

### 11.2 循环

1. `resolve_scope` → 确认现象（目标 vs 基线）。
2. 生成假设：**封闭集合** = {下渣流失, 一罐到底, 冷料 CaO, 供氧不足, 高硅, 配料偏差, 数据质量}；LLM 只能在集合内排序/组合。
3. 每个假设依次 `rule_hits` → `slice_compare` → `regress`。
4. `judge_hypothesis` 用确定性阈值判定（CI 不跨 0 且解释缺口占比 ≥ 阈值）；LLM 不得自行宣布成立。
5. 批评者 → 输出。

**停止**：全部假设已判定；或已解释缺口 ≥ 80%；或预算到（≤ 12 次工具调用 / ≤ 6 轮 / 60 s）；或连续两轮无新证据。

### 11.3 数字引用约束

结论为结构化 claims；正文只允许占位符（如 `{T07.rows[3].recovery_gap|pct1}`），由代码渲染。LLM 自由文本出现任何数字 → 校验器拒绝该段并回退模板。每个占位符必须解析到本次调查 trace 中真实存在的工具结果字段。

### 11.4 批评者（确定性）与降级

批评者检查：每条结论 ≥ 1 条 supported 证据；refuted 假设不得作为原因；越界炉次必须披露；n 过小降级为"待核查"；禁止定责/排名措辞。
**无 LLM（playbook 模式）**：问题解析用规则（日期/班次正则 + 指标关键词）；假设按固定顺序全跑；叙述用模板。工具、数据结构、输出格式与 LLM 模式完全一致。LLM 经 `VERO_LLM_BASE_URL`（OpenAI 兼容，内网 Qwen/DeepSeek 等）可选接入，只做问题解析、假设排序、叙述起草。

结论默认状态"待工艺师确认"；确认/驳回写入发现状态与 trace。trace 以 JSONL 存 SQLite，可回放，即界面证据链。

### 11.5 评测（evals.py）

由 ground truth 模板生成约 60 题（3 个种子）："为什么 {日期}{班次} 品位低""渣批 X 回收率为何低"等；含负样本（正常时段，正确答案 = "未发现显著异常"）与干扰样本（两类异常时间重叠）。指标：top-1 主因命中、top-2 命中（目标 ≥ 90%，不作门槛）、引用合规率、无证据结论数、负样本误报率。剧本模式每次测试必跑（AC-6~AC-9 门槛）；LLM 模式仅出报告，指标不低于剧本模式方可默认开启。
