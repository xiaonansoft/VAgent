## §1 落地总路线：一次只推一个变更面

```
G0 准备（厂内 2~3 周）──→ G1 只读接入 + 影子（4~8 周）──→ G2 advisory（建议上屏）──→ G3 参数闭环
   点表/化验排班/基线        只记录不推送不考核              采纳/否决留痕               漂移检测+专家签字双闸
   双方签字                  联合测基线                     班组考核挂钩                禁在线自改
```

- **切换门按操作包络覆盖度计（非日历）**：影子期覆盖 高/中/低 Si、块状/散状冷料、一罐到底/分罐 等包络分支后，方可申请转 advisory。
- **G2 上屏三前提**（缺一不上）：① 基线双方签字；② 影子期方向性指标达标（趋势/排序一致率、例外炉次召回）；③ 车间签「建议免责、操作负责」纸面规矩。
- **G3 永久红线**：参数变更 = 漂移检测自动触发 + 专家委员会签字，双闸缺一不可；系统永不在线自改。

## §2 两厂差异化定位（互补，不是复制）

| 维度 | A 厂（plant_a · 机理派） | B 厂（plant_b · 查表派） |
|---|---|---|
| 知识资产 | 专家A 四大平衡 Excel（703 公式已复现 75/75） | 专家B 规程查表（基准+温度修正+上限，108 组对照零漂移） |
| 引擎角色 | **供总量 + 品位预测**（全厂唯一有能力预测品位的口径） | **供品种分配结构**（钒渣铁/铁皮/球团优先级） |
| 落地重点 | 冶炼中实时推理（ODE+KF 已在 blow 会话跑通） | 冷料结构 + 枪位模式；切勿把查表拟合连续公式（丢档位经验） |
| 数据基础 | 16 炉反演证据在（真实数据本机私有） | 知识包已入库可复制（plant_b/base.yaml） |
| 首推阶段 | G1 影子直接绑定 CF-001 双口径证据链 | G1 先跑配料结构对照（查表 vs 机理并排） |

**双厂组合拳**：配料 = A 厂总量 × B 厂分配结构；品位预测只有 A 口径——这是「同一引擎、双厂知识包」架构（M18）的活案例。

## §3 系统对接清单（对接哪些系统 —— 核心章节）

| # | 对接系统 | 方向 | 内容与时延 | 接口方式 | 红线/备注 |
|---|---|---|---|---|---|
| 1 | **LIMS 化验系统** | 只读入 | 铁水 C/Si/V/Ti/P/S/Mn/温度；渣样 V₂O₅ 全成分（炉后）；时滞 3~15min | 中间库轮询 / REST / 消息订阅 | **必须标 data_age**——拿滞后数据冒充实时会被炉长一眼拆穿 |
| 2 | **二级机 / PLC 点表** | 只读入 | 枪位、氧流量、累计氧量、吹炼状态、炉体信号；1s 级 | OPC UA / Modbus → **resource:// 适配层**（点表映射配置化） | **只读授权，无写点**；CI 断言 opcua/pymodbus/snap7 仅允许出现在适配层评审通过后 |
| 3 | **副枪 TSC/TSO** | 只读入 | 温度/定碳/定氧，每炉 1~2 次，时滞 30~60s | 文件/消息/点表 | 强融合观测源（blow 会话已按 2min/7min 演示） |
| 4 | **烟气分析系统** | 只读入 | CO/CO₂/流量，1~5s | OPC/消息 | 唯一能反算 dC/dt 的硬源；缺失→软测量兜底并显式降级 |
| 5 | **称量斗 / 天车称重** | 只读入 | 冷料实加品种/重量/时刻 | 点表 + 天车记录 | **最易翻车的断点**：块状料实吊量不回传 → 模型以为加了实际没加，全盘错；合同里写死班组回传义务 |
| 6 | **MES** | 读 + 建议单回写 | 炉次计划/钢种/班次（读）；建议工单（写，人工确认后） | REST | VERO 不改 MES 流程；建议单 = "建议到执行器面前"，MES 侧仍需人工确认 |
| 7 | **时序库 / historian（可选）** | 只读入 | 过程量历史缓冲 | PI/iHyperDB/InfluxDB | 有 historian 的厂可少建一层采集 |
| 8 | **大屏/终端** | 出 | 炉前大屏（6 读数）、平板指令单、工艺台式机 | 浏览器（workbench 同构） | 炉前大屏一屏 ≤6 个核心读数；夜班声光提醒 |

**不对接**（明确不做）：任何 DCS/PLC 写点、急停回路（SIL 硬件专属）、能源/能碳系统、EHS、排产。

### 网络与部署形态

- **部署位置**（五问法结论）：blow 实时推理 + 采集适配层 → **厂内边缘服务器**（近实时，断网 30s 显式降级外推）；复盘/治理/知识包 → **厂内云/内网服务器**；LLM（可选，仅解释/编排）→ 内网化部署或离线模板文案。
- **数据不出厂**：全部 8 项对接都在厂内闭环；跨厂只共享 schema 与方法学，永不共享数值。
- **交付形态**：docker-compose（仓库已有骨架）+ 每厂知识包（`knowledge/packs/<plant>/base.yaml`，不入 git，现场分发）。

## §4 阶段门与 KPI（验收口径，防"编数字"）

| 关卡 | 进入条件 | 出口判据（操作包络覆盖度口径） |
|---|---|---|
| G0→G1 | 点表调研完成；化验排班协议；冷料回传改造验收；客户交 ≥20 炉历史台账 | 采集链路 is_valid=True；数据时延实测入册 |
| G1→G2 | 影子 ≥100 炉覆盖主要包络；基线双方签字 | 方向性指标达标（趋势/排序一致率、例外召回）；零下发审计通过 |
| G2→G3 | 采纳率与偏差带达分档口径 | 每次参数变更 100% 双闸留痕 |
| 转正门槛 | **默认档**：去偏后 粗渣 ≤0.9pp / 精渣 ≤1.3pp；**进阶档** ≤0.5pp 须 CF-001 终审 + 补齐铁水 C/温度/分品种冷料自由度后另议 | 对照对象锁定粗渣装车样；精渣仅参考 |

KPI 七项与数据源对表沿用 `VERO_FULLCHAIN_SPEC` §9；效益一律「基线 ±Δ」，他人案例数字不入 KPI。

## §5 商务与工作量（沿用既定 SKU，此处不重新谈判）

- 一次性平台投入 **40 人日**（数据源适配层 12 + 前端桥接 5 + 回放/影子/评测 10 + 看板 3 + 知识包脚手架 5 + GATE-2 5），不进二厂报价。
- 每厂实施 **22~27 人日**（标准接入；含标定+影子期 12~15、冷启动盯现场 2 周、每日对齐会）。
- CF-001 终审 = 合同里程碑 CC-1 双出口：甲=首炉上线前甲方定一个全局 dh_v；乙=逾期则双案并存 UI 显示预测区间（+3~5 人日，引擎本就跑双案）。
- 商业模式：按炉订阅（主推）+ 影子期免费联合测基线 → 对赌分档（达标转正/阶梯价/无条件终止）。

## §6 落地第一公里的五个坑（人 和 流程，不是技术）

1. **班组抵触**："系统在考他" → 上线前两周只显示不评价，先混脸熟。
2. **化验时延**：系统拿滞后数据推"实时" → data_age 显式标注 + 炉长教育。
3. **天车留痕断点**：称量/吊运实绩必须回流（§3-5），否则证据链断。
4. **责任归属**：不先签「建议免责、操作负责」，没人敢点采纳。
5. **夜班无人看屏**：建议声光一体 + 值守室同步，只亮屏等于没发。

## §7 演示脚本（今夜系统已可跑，15 分钟）

**启动**（1 分钟）：
```bash
cd ~/Documents/VAgent/backend
python3 -m uvicorn app.main:app --port 8000
open http://127.0.0.1:8000        # 自动进入工作台
```

**① 开吹（3 分钟）**：默认铁水条件点「计算配吃方案」→ 出配吃量/品位预测/双口径仲裁（两案球团差 ~520kg，CC-1 挂牌）→ 讲三要素证据链（规则版本/机理/相似炉次）。

**② 吹炼·实时推理（6 分钟，核心）**：场景选 `hot_metal`（铁水超温，化验单不知道——真值对界面不可见）→ 倍速 10 → 「开始吹炼」→
- 看轨迹图：估计线贴着方案基线走，σ 带随外推展开，2min 副枪样落入（蓝点）；
- 红外/副枪数据陆续进入后，系统察觉真实温度高于化验口径 → **建议卡弹出**：「预计 X 分钟后越过 Tc 1361℃（残钒尚有 0.2xx%），建议 N kg 散状冷料压温」+ 倒计时；
- 点「采纳（模拟操作工执行）」→ 轨迹压回 Tc 以下 → 预测终点温度回落；
- 讲清三件事：**系统没有执行通道**（采纳=操作工执行的演示语义）；**窗口一过建议自动失效**（不留马后炮）；**块状料炉次根本不会出这条建议**（不给做不到的建议）。

**③ 复盘（3 分钟）**：吹炼终点自动跳复盘 → 真值揭示：预测 vs 真值偏差、σ 带覆盖率（校准诚实度）、建议审计流水（谁/何时/采纳/当时快照）→ 「确认入台账」→ learned_entries 为 DB 真实计数。

**④ 治理（2 分钟）**：冲突清单三层聚合（plant_a 缺失显式降级——诚实口径）；模式切换 PRODUCTION 用错 token → **403 诚实拒绝**（对比行业里"假装成功"）；四条红线全部技术强制（CI 门禁）。

**收尾一句话**：控制零触碰，知识全留痕——我们不替代操作工的手，我们沉淀操作工的脑。
