## 1. 产品定义

- **一句话描述**：基于 VERO 已验证资产升级演进的"提钒→半钢双联全流程可解释推荐"智能体系统蓝图——冶炼前配料优化、冶炼中实时推荐、冶炼后质量复盘，三阶段 × 两工序全覆盖，适配攀钢/建龙双厂。
- **目标用户**：内部研发团队（蓝图文档的直接读者）；次级读者：转炉主控室操作工、工艺工程师、炼钢厂管理层（蓝图所设计系统的最终用户）。
- **核心问题**：全行业都在做"自动执行的黑箱"，跨两道转炉的工序衔接 + 三阶段闭环 + 知识治理是公共空白；半钢段是命中率洼地（碳温双命中 80.71% vs 普通铁水 90%+），跨工序衔接全靠人工经验传递。

## 4. 技术架构（锁定）

文档形态技术栈（蓝图 HTML 本身）：

| 层 | 技术 | 版本 | 锁定原因 |
|----|------|------|----------|
| 文档载体 | 单文件 HTML（零构建/零 CDN/零 JS 框架） | HTML5 | 离线红线：数据不出厂；工程师 VS Code 直接改 |
| 样式 | 内联 CSS，全部走 :root Design Token | - | 改 3 个变量即换肤；design-system/design-tokens.css 原样内联 |
| 图标 | Lucide（<symbol> sprite 内联） | 最新稳定 | P0 裁决：MIT/24px/2px 描边；禁止 emoji、禁止混用第二库 |
| 架构图 | CSS Grid 分层横条（总图）+ 手写内联 SVG（数据流大图，fill 引用 Token 变量）+ flexbox 步骤条 + CSS Grid 时间轴 | - | Mermaid 否决（离线体积/自动布局不可控）；文字直改保证可编辑性 |
| JS | 仅 3 件事：TOC 滚动高亮、章节折叠、designMode 编辑开关 | 原生 | 禁止把内容藏在 JS 数据里 |

系统架构（蓝图所设计的 VERO 升级架构，五层）：应用层（驾驶舱/仲裁工作台/治理看板）→ L3 智能体编排层（LangGraph 三阶段图模板 × 双工序实例）→ L2 机理引擎层（八大既有引擎 + sdm_semisteel_balance + reheating_agent_solver 新增）→ 数据层（DATA_INTERFACE_SPEC v0.2 + semisteel_transfer 契约 §3.6 + 软测量）→ L3' 学习治理层（RLS 双段独立参数组 + 知识包审批流 + mode_control 三态）。

## 6. 页面版式（锁定）

- 桌面 ≥1024px：左侧 216px 粘性 TOC（滚动高亮）+ 中央 1200px 阅读列 + ≥1440px 右侧"本页速览"栏
- 移动端：TOC 折叠为顶部锚点条
- 章节锚点 #hash 深链 + scroll-margin-top
- 浅色文档风（人因实证），驾驶舱 v0.9 深色不动
- 字体：Inter/HarmonyOS Sans SC 栈 + JetBrains Mono 等宽；正文 14px/1.75，表格 13px，数据强制 tabular-nums
- 三轴刻度：DESIGN_VARIANCE=3 / MOTION_INTENSITY=2 / VISUAL_DENSITY=7

## 7. 设计 Token（锁定 — 已落盘）

- 文件：design-system/design-tokens.css + design-tokens.json（四层：A1 原始→A2 语义→B 组件→C 项目扩展）
- 墨色阶 #141D2B/#3D4A5F/#6B7686/#98A1AE；纸面 #F6F7F9/#FFFFFF/#EFF1F4（冷灰裁决已采纳）
- 铁水橙 #E8590C（图形）/#C2410C（文本安全）；钢蓝 #2B4A6F；语义色 success/warn/danger/info 各配 100 级 tint
- 域色：橙=提钒域、钢蓝=炼钢域、灰 #6B7686=公共底座；禁止第四种域色
- C 层预留 plant-variant 语义（--plant-a/--plant-b 别名，仅知识包版本标注用，不入域色体系）
- 间距 4px 网格 s1-s8；圆角 6/8/12/999；阴影两级优先 1px 边框；焦点环 rgba(232,89,12,.35)

| AC-04 | When 用户查看 §3 架构总图，必须呈现五层 × 双工序骨架，节点总数 ≤22，每个工序内冶炼前/中/后合并为分组节点 | P0 |

## 9. 边界与约束

- 单文件体积目标 ≤800KB（Lucide sprite 仅内联所需图标，预计 20-30 个）
- 不支持 IE；响应式断点 1024/1440
- 文件命名：VERO_FULLCHAIN_BLUEPRINT.html，置于项目根目录
- 厂名规则：文档叙述可用攀钢西昌/承德建龙厂名；仓库代码/知识包维持 plant_a/plant_b 脱敏别名（C18）

## 10. 内嵌已知坑（从项目记忆拉取）

| 坑 | 指纹 | 根因 | 修法 |

## 11. 端到端验证步骤（QA 执行）

```bash
# 1. 离线渲染：断网状态打开 VERO_FULLCHAIN_BLUEPRINT.html，全部章节渲染完整
# 2. emoji 扫描：用 P0 正则扫描全文（排除 Unicode 转义注释区），命中数 = 0
# 3. 硬编码色扫描：grep style 属性十六进制色值（#fff/#000 除外），命中数 = 0
# 4. 渐变扫描：紫粉渐变正则 + 弹跳缓动正则，命中数 = 0
# 5. 结构核对：M1-M18 / C1-C18 / KPI ≥7 项 / 切换门覆盖度口径 逐项对表
# 6. 深链测试：粘贴 #§5 类 hash 直达章节，TOC 高亮正确
# 7. 编辑模式：开启 designMode 修改一段文字，验证可复制导出
```
