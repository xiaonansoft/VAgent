## §1 使命与边界

- 使命：降本提质——实时推荐冶炼参数与操作细节，助力炼好每一炉钢、做好提钒。
- 差异化定位（已获用户认可）：全行业都在做"自动执行的黑箱"，VERO 做的是**提钒→半钢双联全流程的可解释、可治理、可进化的推荐**。单工序各有强者（攀钢提钒自动化、成渝钒钛半钢数字炼钢、西昌热平衡计算专利、达涅利 SDM/宝信/包钢智能炼钢），但跨两道转炉的工序衔接 + 三阶段闭环 + 知识治理，全行业无人覆盖。
- 边界：覆盖提钒冶炼 + 半钢冶炼（双联工艺）双工序全流程；上游高炉/烧结含钒铁水预报接口预留；下游钒渣提钒加工（钠化/钙化焙烧）仅数据契约预留。
- 三条永久红线：永不写控制回路（只出建议）；数据不出厂（内网部署、生产路径 0 外部 LLM API）；决策路径 0 LLM（10 秒实时推荐路径全部为确定性机理+规则，LLM 仅异步解释）。

## §4 全链路数据流（双工序生命周期，15 节点，按 DESIGN.md 附录 B 四带泳道）

橙泳道（提钒域）：① 铁水到达（化验 C/Si/V/Ti/P/S/Mn+温度/重量+上一炉留渣/蓄热）→ ② 冶炼前·配料优化（M1-M3：四大平衡主算+冷却剂查表+Si 扫描帕累托方案集）→ ③ 开吹（SSE 1s tick）→ ④ 冶炼中·实时推荐（M5-M8：软测量态估计/ODE 10s 步前推/偏差检测触发推荐/TSC 副枪事件卡尔曼重锚）→ ⑤ 终点判定（残钒/温度/碳三判据）→ ⑥ 冶炼后·复盘归因（M9-M12：品位归因/误差登记/判例沉淀）
中央交接区：⇒ 【渐变交接箭头，全文档唯一渐变】semisteel_transfer 契约（M14：半钢 C 3.0-4.2%/V 残 ≤0.05%/Si ≤0.05%/温度+时刻戳→SDM 温降公式折算/热补偿标记/带渣量估计）——半钢交接节点为全图唯一 2px 加粗边框
钢蓝泳道（炼钢域）：⑦ 冶炼前·半钢配料（M15：SDM 静态吹炼计算+提温剂组合求解——焦炭/硅铁/碳化硅，约束=回硫上限/渣量上限/成本）→ ⑧ 半钢吹炼（M16：主吹→TSC 动态计算→TSO→补吹建议，对齐 SDM 静-动-补吹时序）→ ⑨ 终点碳温双命中判定 → ⑩ 出钢+钢包合金化（预留）→ ⑪ 冶炼后·半钢复盘（M17：碳温命中登记/提温剂成本核算/回硫核对/三通道误差归因）
底部灰数据带：⑫ 采集网关 → ⑬ 软测量（correction_source+置信度）→ ⑭ RLS 误差回流（提钒 θ / 半钢 θ' 独立，虚线回指两泳道）→ ⑮ KPI 看板+判例库/AdviceLog
箭头语言：实线=主工艺流 / 虚线=数据流 / 点线=RLS 知识回流 / 渐变箭头=双工序交接（唯一）。

## §9 效果验证方案
