# 提钒冶炼 + 半钢冶炼痛点、冶炼智能体与本体构建方案（v1.1）

> **修订说明（2026-09-30 专家评审后）**：根据冶金工艺 / 本体论 / AI 架构 / 竞品核查四维度评审，做如下修订——
> **P0**：① 修正核心卖点"提钒空白"为"大模型/智能体级 + 本体 + 跨工序协同空白"（传统智能控制已有攀钢、承德先例）；② 本体顶层谱系由误用 BFO 改为随 CROS（MASON/SOSA-SSN/UFO）或 IOF Core。
> **P1**：补 S 值前提、区分顶吹/底吹温度窗口、放宽 [Si]；收敛"自愈控制"与缺陷检测表述；工具栈补 OT 安全与 MLOps；工作流改分级自治闭环；本体补 Observation/Sensor/Energy 类与关系规范化。
> **P2**：补半钢泄爆、钒渣带铁损失、深吹过氧化 3 个痛点，以及承德钒钛、攀钢"钢铁大脑"标杆。
> 文中【事实】为公开/权威可证实；【分析】为综合推演；【建议】为行动项。

## 0. 业务链条一句话梳理

钒钛磁铁矿经**高炉冶炼 → 含钒铁水 → 转炉提钒（氧化 V 入钒渣）→ 半钢 → 转炉/炉外精炼炼钢 → 连铸轧制**。

> 【事实】"半钢"是含钒铁水经提钒（或"三脱"预处理）后，硅锰为痕迹、碳降低约 0.5–1%、发热元素烧损较大的中间产物[3][4]。提钒与半钢炼钢是同一流程上强耦合的两段，痛点互相传导。
> 【修订提示】提钒传统智能控制已有先例：攀钢《转炉智能化提钒工艺技术研究》2014 年获四川省科技进步二等奖（自动化提钒 85.98%、半钢碳命中 92.98%、钒回收率 80%）；承德钒钛 2024 年投运行业首发"提钒转炉全自动智能控制系统"（静态+烟气动态模型、自动加料/出钢）[专家评审核实]。

## 1. 提钒冶炼 + 半钢冶炼的痛点

### 1.1 提钒冶炼痛点

| 痛点 | 机制 / 表现 | 来源 |
|---|---|---|
| **"提钒保碳"窗口极窄** | 需把熔池温度控制在 1350–1420℃（顶吹窗口；底吹 1300–1400℃，热力学原则上限 <1400℃）：过低钒氧化不完全，过高碳大量烧损（碳是后续炼钢热源）；Si 对 C、V 氧化有强抑制；终点半钢余钒 >0.04% 需补吹[2] | 【事实】 |
| **多数产线控制仍依赖人工静态控制** | 提钒转炉普遍无副枪、无烟气检测，处于静态控制；国内多数仍靠操作工经验手动操作，致半钢、钒渣质量不稳。**注：承德钒钛 2024 年已实现行业首发全自动智控，属先发标杆而非普遍状态**[2][专家评审核实] | 【事实，已校正】 |
| **钒回收率与钒渣品位偏低** | 攀钢现工艺钒回收率低于国外，钒渣品位、钒氧化率有待提高；铁水 [V]≈0.3% 的低钒提钒机理研究少[2] | 【事实】 |
| **钒渣带铁损失与挡渣难题** | 钒渣 TFe 高、半钢带钒渣入罐，直接制约钒收得率（攀钢约 66%），是提钒段核心损失点[专家评审核实] | 【分析】 |
| **湿法提钒环保与成本压力** | 钠化焙烧–水浸产生大量含盐废水、含铵芒硝难处理、提钒尾渣钠高难利用；需补建热力学数据库与迁移动力学模型[1] | 【事实】 |
| **冷却剂制度复杂且经验化** | 冷却能力排序：冷固球团 > 绝废渣 > 钒渣 > 生铁；需精确控制种类、加入量、加入时机，缺乏模型支撑[2] | 【事实】 |

### 1.2 半钢冶炼痛点

| 痛点 | 机制 / 表现 | 来源 |
|---|---|---|
| **热源不足** | 半钢 C/Si/Mn 烧损大，转炉化学反应热比常规铁水减少约 **20%**，升温困难、多吃废钢困难[3] | 【事实】 |
| **化渣困难** | 半钢硅锰为痕迹，渣系基本为 CaO–FeO 二元体系，熔点升高、成渣慢、易粘枪粘炉口、中期返干[3][4] | 【事实】 |
| **脱磷脱硫困难** | 初期渣形成晚、渣系单一，脱磷率低；提钒用酸性渣无脱硫能力。**前提说明**：文中"半钢 S 0.04–0.07%"系建龙高硫铁水且不预脱硫（保钒渣质量）的特定场景；攀钢主流"预脱硫→提钒"流程后半钢 S 可低至 0.002–0.03%，不可一概而论[3][5][专家评审核实] | 【事实，已校正】 |
| **带渣污染** | 出半钢时部分钒渣随钢流进入半钢罐，影响成渣与溅渣效果[4] | 【事实】 |
| **温度窗口窄 + 纯净度要求高** | 提钒热力学原则上限 <1400℃，半钢温度偏低；高端管材要求成分窄波动、S≤0.002%、P≤0.012%，存量钒析出机制与添加钒不同，需控轧控冷[5] | 【事实】 |
| **开吹泄爆风险（半钢特有）** | 半钢无 Si 氧化期，开吹即进入激烈碳氧反应，干法除尘系统易泄爆，是半钢冶炼特有安全痛点[专家评审核实，CN104313235B] | 【分析】 |
| **深吹过氧化** | 热源不足→提温剂抑 FeO→化渣差→被迫深吹，致钢铁料消耗升高[专家评审核实] | 【分析】 |
| **质量波动** | 不同批次性能波动大（纯净度、尺寸精度影响服役安全），需精细化工艺保证[5] | 【事实】 |
| **成分表述校正** | 半钢 [Si] 建议取 ≤0.02%（专利常给 0.001–0.02%），[Mn] 0.02–0.04%，[C] 3.0–3.9%（原 3.0–3.8% 略窄）[专家评审核实] | 【事实，已校正】 |

> 【分析】两段痛点本质是"黑箱 + 经验依赖 + 多变量强耦合"：提钒段质量波动直接决定半钢段热源/硫磷边界，半钢段化渣/脱磷难度又反限提钒温度制度。任一端控制缺失都向下游放大损失。

## 2. 冶炼智能体能做什么

> 行业已验证能力（2025–2026 落地案例）[6][7][8][9][10]：

| 能力层 | 已验证做法 | 代表指标 |
|---|---|---|
| **感知（破黑箱）** | 多传感器 + 数字孪生 + "感侧/知侧"双塔大模型，实时判炉况 | 南钢高炉提前 2h 预测炉温，准确率 90%+[8] |
| **预测** | 炉温、铁水温度/成分、硅含量预测；AI 配矿 | 南钢配矿年降本超 3 亿元[8] |
| **控制 / 决策** | 转炉智能吹炼、终点碳温双命中、一键炼钢 | 宝钢 89%、唐钢 90%+，周期 −3min[7][9] |
| **诊断 / 辅助** | 故障诊断（知识图谱）、实验验证的自愈控制 | 高炉多层图谱诊断准确率 92.76%（**论文实验值，非产线落地**）[12] |
| **质量** | 金相分析、缺陷检测、表面质检、钢卷评级 | 金相分割准确率 >95%（缺陷检测 >95% **缺权威出处，待核**）[6] |
| **知识传承** | 自然语言问答给操作建议，经验可复制 | 南钢"元冶"让新手快速上手[8] |
| **配料 / 排程** | 一体化配料、智慧排程 | 吨铁降本 10 元+、单机组 179 万元/年[7] |
| **成本 / 绩效** | 单卷成本、岗位精算 | 佰工吨钢降本 82 元[10] |
| **安全 / 物流 / 环保** | 视觉安防、物流管控、排放监控 | 安防 98%、湛江物流年效益 3971 万元[7] |

### 映射到"提钒 + 半钢"的具体能力【建议 + 差异化】
- **提钒段**：提钒保碳动态控制、冷却剂优化、钒回收率与钒渣品位预测、余钒终点命中。
  > 【分析·关键修正】提钒**传统智能控制已有先例**（攀钢 2014 省奖、承德钒钛 2024 全自动智控），因此定位不是"从零空白"，而是 **"大模型 / 智能体级 + 本体语义底座 + 提钒—半钢跨工序协同"仍属空白**，是更精准的高价值切入点。
- **半钢段**：化渣预测与造渣剂推荐、脱磷脱硫终点控制、温度补偿（提温剂加入量）、废钢比优化、带渣在线检测、成分窄波动控制。

## 3. 冶炼智能体参与哪些业务

> 参考宝信"20 个核心环节"、南钢"21 大业务领域"、佰工"全链路"[7][8][10]，覆盖全价值链：

**纵向工序链（生产侧）**：铁前（配矿/烧结/球团/高炉）→ 炼钢（**提钒→半钢炼钢→转炉吹炼→精炼→连铸**）→ 轧制 → 质检。

**横向职能域（经营侧）**：设备预测维护、能源管控、供应链协同、单卷成本经营、安全环保。

> 【分析】对钒钛磁铁矿企业，最独特价值在"提钒—半钢"段：横跨铁前（钒收得率）、炼钢（热源/硫磷）、质量（纯净度）、成本（钒合金自产）。标杆承德钒钛、攀钢"钢铁大脑"已在此段有智能化积累，本方案应以"大模型 + 本体 + 跨工序协同"形成代差，而非重复已有单点控制。

## 4. 工具与工作流

### 4.1 工具（能力组件栈）

| 层 | 工具 / 组件 | 说明 |
|---|---|---|
| 感知 | 视觉大模型（钢铁万物分割）、声学、红外、SCADA/OPC-UA 传感器 | 打破黑箱[6] |
| 边缘 | **边缘实时推理节点**（补） | 提钒炉无副枪，须先补硬件感知与边缘低延迟推理 |
| 模型 | 机理模型 + 数据模型 + LLM + 视觉大模型（"左脑/右脑"） | 南钢"元冶"范式[8] |
| 知识 | 知识图谱 / RAG、行业知识库、CROS 本体 | 检索与推理底座 |
| 编排 | 智能体编排平台、Workflow / 工具调用 | 多智能体协同 |
| **安全 / 自治** | **OT 安全联锁、权限分级、分级自治引擎、MLOps 回滚（补）** | 防止"直下发 DCS"失控 |
| 数据 | 数据治理、孪生数据引擎、语料库 | 2.5T Tokens 级语料[7] |
| 算力 | 智算中心（宝之云，公开口径约 100P，需核对） | 训练与推理底座 |

### 4.2 工作流（分级自治闭环，修订）

```
① 数据治理   → 统一语义接入（MES/SCADA/LIMS），清洗标注，建本体底座
② 孪生仿真   → 上线前数字孪生仿真验证策略，灰度/回滚预案
③ 感知采集   → 实时炉况/成分/烟气/视觉（提钒炉先补硬件感知）
④ 工况认知   → 感知大模型判炉况（提钒？半钢？化渣早晚？）
⑤ 工艺推理   → 本体+机理+历史案例 → 推荐参数/冷却剂/吹氧制度
⑥ 人环确认   → 安全门：自动闭环仅限低危设定；高危/首炉经操作员确认（人环）
⑦ 分级执行   → 下发 DCS（受 OT 安全联锁约束），MLOps 监控与异常降级
⑧ 知识沉淀   → 异常案例入图谱，规则补全
⑨ 跨工序协同 → 半钢[C]/[S]/温度 → 炼钢配料与温度补偿联动
⑩ KPI 评估    → 钒回收率↑、余钒命中↑、半钢脱硫率↑ 闭环度量
```

## 5. 用本体论（Ontology）构建冶炼业务

### 5.1 为什么用本体
> 【事实】钢铁流程工序长、层级多、命名不一致、知识分散，缺统一语义易停留在"字段拼接"[13]。CROS（Core Reference Ontology for Steelmaking, Cao et al. 2022）已形式化描述炼钢过程、工具、资源，用于语义互操作与条件维护[11]；高炉多层本体引导知识图谱取得 92.76% 诊断准确率（实验）[12]。

### 5.2 分层本体设计（修订：修正顶层谱系）

**顶层（复用，二选一，不可混用）**：
- *方案A（推荐，随 CROS）*：基于 **MASON / MSDL / SOSA-SSN / UFO** 谱系（CROS 实际复用体系）；
- *方案B*：采用 **IOF Core（BFO 谱系）**，顶层为 Continuant/Occurrent。
> 【修订】原文误将 CROS 与 BFO 并列——CROS 不基于 BFO；"SSO" 应为 **SOSA/SSN**。Resource/Capability 属 IOF Core/CCO 谱系，Constraint 为信息实体，勿作 BFO 顶层类。

**领域层（提钒 + 半钢专属）**：
- **实体类**
  - 物料：含钒铁水、钒渣（兼"冷却剂角色" Role 模式）、半钢、钢水、冷却剂、造渣剂
  - 设备：高炉、提钒转炉、炼钢转炉、氧枪、底吹元件、挡渣/聚渣装置
  - 工序：高炉冶炼 → 提钒 → 半钢炼钢 → 精炼 → 连铸（用 `precedes` 表达先后）
  - 参数：**归入 Quality/Measurement**（挂测量主体），如温度、[V]、[C]、[Si]、[Mn]、碱度、FeO、余钒
  - 能源（**补 Energy 类**）：煤气、电、提温剂热值（承接"消耗能源"边）
  - 观测（**补 Observation/Sensor/Measurement 类**）：接 SCADA 高频时序，除 OBDA(R2RML 静态) 外补流式接入
  - 钢种 / 缺陷 / 规则 / 专家经验
- **关系（规范化为动词谓词，定义 domain/range 与方向）**：`hasInput` / `hasOutput`（含 `hasByproduct`：含钒铁水→钒渣）/ `participatesIn` / `constrains`（提钒保碳窗口约束工序）/ `causesDefect`（化渣困难导致缺陷）/ `precedes`
  > 【修订】"提钒保碳约束 / 化渣困难 / 脱硫受限"是**约束/状态，非谓词**，应建模为 Constraint/Dispositional 节点，经 `hasConstraint` 关联工序，数值窗口用 **SHACL shape** 承载，而非直接作语义边。
- **属性与约束（工艺窗口）**：提钒顶吹温度 1350–1420℃（底吹 1300–1400℃）、余钒 <0.04%、半钢 [C] 3.0–3.9%、[Si]≤0.02%；安全/环保约束。
- **规则（if-then 语义模板）**：用于诊断/控制/预测的子图采样[12]。

**实例层（知识图谱）**：结构 + 语义 + 属性融合，图嵌入支撑预测/控制。

### 5.3 构建七步【建议】
1. 定范围 → 2. 复用扩展（CROS/MASON 或 IOF Core）→ 3. 专家+文档抽取 → 4. OWL 形式化（SWRL 推理 + SHACL 约束校验）→ 5. 实例化（MES/SCADA/LIMS/OBDA + 流式）→ 6. 接智能体 → 7. 持续演进。

### 5.4 与智能体结合点
本体 = 共享语义底座 + 长期记忆；RAG 检索降幻觉；SHACL 规则实时校验工艺窗口；按关系自动编排 感知→推理→执行 链路。

## 6. 关键结论与不确定性（修订）

- 【事实】提钒 + 半钢核心痛点是"黑箱、经验依赖、多变量强耦合 + 环保成本"，两段相互放大。
- 【分析·已校正】**提钒传统智能控制已有攀钢、承德先例**，本方案的精准定位是"大模型/智能体级 + 本体 + 跨工序协同"空白，对钒钛磁铁矿企业是差异化切入点。
- 【建议】以"提钒保碳控制 + 半钢化渣/脱磷脱硫控制 + CROS 扩展本体"为三支柱，先竖单炉闭环再横向复制；对标承德钒钛/攀钢，主打代差。
- 【不确定性】提钒侧多数产线感知薄弱（无副枪），"破黑箱"须先补硬件；低钒机理研究少、炉次数据量小，炼钢段精度不可直接外推；本体须先消解顶层谱系与关系语义两处硬伤方可形式化。
