叙事抄形 · 架构守神 · 验收抢先。

  • 叙事抄形：借鉴同行已付费的市场教育成果——"数字员工 / 数字班组 / 岗位能力包"这套语言可以讲，它打开的是厂长口袋里的人工成本替代预算。
  • 架构守神：人格化只活在交互层与销售层（PPT、演示视频、投标封面、管理层汇报）；计算拓扑永远是单编排器 + 确定性工具集；一线操作界面与留痕零人格化。
  • 验收抢先：同行公开叙事中没有一个量化指标。这是我们最大的机会——抢在别人之前定义"数字员工该怎么验收"，谁定义验收，谁定义赛道。

01 · 一句话定位与备选定位语

首选定位语（对外默认使用）

「不做黑箱自动驾驶，做总工的机理副驾。」

为什么这句最好使：① 主动否定"自动驾驶"，把 AI 盲目上回路的风险先拆掉，消除甲方总工/安全口的本能抵触；② "机理"二字宣告我们有确定性底座，不是 Prompt 工程；③ "副驾"承担了责任边界——方向盘在人手里，但人不孤独；④ 主语是"总工"不是"操作工"，避免触发一线"来顶我岗的"抵触。

配套一句解释（被追问时用）："它是坐在您的机理模型和知识包之上的一层认知层，负责把数据翻译成带证据的动作建议，建议怎么来的每一步都能查，最后要不要照做，您点头才算。"

编号定位语适用对象使用要点与话术落点
P0
首选		 不做黑箱自动驾驶，做总工的机理副驾 总工 / 厂长 / 评标专家 主打场景：技术交流会、投标答辩、专家评审。默认用语，所有材料标题级必带。落点＝"建议可解释、可追溯、可推翻，最终决策权在现场"。
P1 给每一炉配一个不睡觉的编外班组 厂长 / 生产副厂长 / 人力资源 主打场景：立项汇报、预算沟通。落点＝"三个班、四班倒的人头压力；夜班最薄弱的那几个小时"。注意：这句话只用于管理层口头表达，不得印在一线操作界面、不得写入操作记录。
P2 把老师傅的经验变成可盘点、可审计、可继承的厂内资产 厂长 / 总工 / 信息化部门 主打场景：知识工程、数字化转型、接班人断层议题。落点＝"人员退休不带走产线能力"+"三条：经验的采集、确权、复用"（详见 docs/EXPERIENCE_CAPTURE.md）。
P3 只建议、不下发：一条叫得应、说得清、查得到的工艺建议流 信息化部门 / 自动化厂商 / 评标专家 主打场景：集成边界谈判、安全评审、自动化厂商协作。落点＝"不替代 MES/L2，只读 DCS/SIS，AI 直发设定值次数＝0，可审计"。这是化解集成政治阻力的钥匙句。
红线提示（定位语使用三不）
  • 不在一线界面上用：一线操作界面与留痕中出现的主语只能是"系统 / 机理引擎 / 模型 vX.X"，不能出现"数字员工""AI 同事""小张"。
  • 不承诺架构做不到的能力：不得说"多个数字员工自主协商、自动交接、闭环执行"；正确说法见 §05 演示脚本。
  • 不承诺未经采集的 KPI：只能引用 VERO_ACCEPTANCE_WHITEBOOK.html 中"已有真实数据"一栏的指标，其余一律标"（待采集）"。

03 · 三角色话术卡

卡 A · 对厂长

他关心：人头、夜班、安全、减活。预算科目＝人工成本替代 / 智能化技改。

开场 30 秒
"厂长，我不跟您讲算法。我只讲三件事：人头、夜班、安全。合格的提钒操作工要五六年才养得出来，最便宜的老师傅也在退休；夜班两三点是最容易出偏差的时段；一出喷溅，损失的不是钢水，是这个月的奖金和您一年的安全分。我们要做的，是给每一炉配一个不睡觉的编外班组。"
讲钱
锚点数据（均为已有真实数据，可对账）：已部署的 PS 转炉造渣终点判断准确率 96.0%；单炉年化增收测算 420 万元；全厂推广口径年营收增收 1280 万元、利润 460 万元；在谈新合作项目规模 927 万元。
注：以上数字来源与口径见《可验收标准》白皮书 §03，对外必须连同计算口径一起给，不允许裸给。
讲减活
"我们不给您加活儿。原来要跨三个系统查、Excel 上算、纸质台账记，现在就一块屏一轮确认。能删的步骤我们删，不能删的我们自动填。"
收尾
"我不要您相信 AI。我要您给我们一个能验收的指标——终点命中率。数据说话，达不到按合同办。"

卡 B · 对总工

他关心：机理站不站得住、结果能不能解释、口径谁说了算、能不能沉淀成资产。

开场
"我们是机理优先。四大平衡（物料/热量/冷料/钒）是专家A专家模型的还原，不是拟合出来的黑箱，黄金回归 75/75，最大误差 0.0002%；JS 端移植 11/11 与 Python 完全一致。"
讲可解释
"任何一个数，都能追到三样东西：哪条公式、哪个数据来源、哪个知识包版本。LLM 不做计算，只做包装；数值溯源失败就拒绝输出，这是硬编码的红线，不是承诺。"
讲口径治理
"我们最值钱的不是模型，是口径登记册。跨厂规程打架的地方，比如碳钒转化温度到底是 1361 还是 1380、V/(Si+Ti) 判据阈值多少，我们全部登记成 CF-001～CF-008，每条有证据、有仲裁结论、有版本号。吵架吵进系统里，不再吵在会上。"
讲知识包
三层结构 industry（行业通用）→ plant_b / plant_a（厂级覆盖）→ 车间/炉座（预留）。行业通用规则打底，厂级参数覆盖取值。换一座炉，换的是覆盖层，不是重做一遍。
收尾
"您不需要把它当成同事，当成副驾就行——它给建议、给依据、给历史判例，方向盘始终在您手里，推翻它就是给它上课。"

卡 C · 对信息化部门

他关心：会不会取代我、网络边界、数据主权、出事谁负责、实施期多长。

开场（先让他放心）
"我们不替代 MES，也不碰 L2。我们是坐在现有系统之上的一层建议层——您原来的东西一个字不改，我们只做读取和建议。"
讲边界
· 接口方向：只读，从 DCS / SIS / 化验 / MES 取数，不回写控制回路
· 建议如何到现场：屏幕上给建议 + 人点确认；不下发设定值
· 可审计条款：LLM 直接下发设定值次数 = 0，可随时查日志验证
· 部署形态：数据不出厂，可全本地部署 / 内网私有化
讲集成成本
"现有 7 个确定性计算能力已通过 MCP 工具协议注册，工具是接进来而不是写进来；数据接口按已发布的《数据接口规范》对接，六个数据源（化验/PLC/副枪/烟气/台账/前端适配器）逐个开通，没开通的部分明确标"不可用"，不假装可用。"
收尾
"我们这条红线是可以写进合同的：建议必须经人确认；AI 直发设定值次数为 0。真出了事，责任边界是清楚的——因为我们留痕里从来没有"人"，只有系统、版本和时间戳。"

04 · 「提钒岗位能力包」叙事模板（资产化与订阅制）

4.1 为什么更名

"人天交付"把产品讲成劳务：交付完就结束、报价被比价、能力沉淀归乙方看不见。"提钒岗位能力包"把它讲成资产：可盘点、可增值、可复购。同一个 §04 就是乙方的资产台账，也是甲方的采购清单。

4.3 三段式资产化话术

① 可盘点——"给您一份清单一共几行：行业基线 1 份、厂级包 1 份、口径登记 8 条、确定性 Skill 7 个、结构化经验 N 条。每一行都能点到有源码、有版本号、有回归测试。这就是您买到的东西，不是一场咨询。"
② 可增值——"它会长大。每推翻一次系统并被证明是对的，就多一条判例；每位师傅讲的一条经验入库，经验包就厚一分。用得越久，这个包越值钱，而它记在您厂名下。"
③ 可复购——"第二条线不需要重买一遍：行业包不动，只做一份厂级覆盖包。第一次是项目费，往后是能力包订阅费。"

06 · 竞品应答卡（客户拿同行文章来问时的标准答案）

应答总原则：不批评对手，只升维。
对手的存在是好事——他们替整个行业付了"数字员工"的市场教育费。我们唯一的动作是把话题从"有没有"拉到"怎么验收"。任何贬低同行的话语都会让客户警惕；任何一次抬高验收标准的话都会让客户记住我们。

6.1 客户原话 → 标准应答

客户可能怎么说标准应答（可照读）潜台词与纪律
"人家中铝都上数字班组了，你们有没有？" "有，而且我们在产线上跑着。不过我想先把话说明白——我们对'数字班组'这四个字的理解，和大家不太一样。我们认为：角色应该是同一套引擎的不同视角，而不是几个各自算一遍再互相传话的智能体。传一次话，就多一次信息损耗和幻觉注入的机会。所以我们是单引擎、多视角——不存在交接幻觉链。这也是我们敢把话写进白皮书的原因。" 不否定对手，把差异讲成架构选择而非能力高低
"人家的数字员工能联动更新全部控制参数。" "这句话要看怎么理解。如果是'约束变了，系统全链路重算并给出新建议'——这个我们也有，而且这是我们最看重的能力之一。如果是'系统自己去写控制参数'——这个我们不做，也建议贵厂慎重。理由很简单：一条脏数据如果拿到了改工艺设定的权限，事故半径就不可控了。我们的红线是可以写进合同的：AI 直发设定值次数等于 0，随时可以查。" 反守为攻的核心一答。语气是善意提醒，不是指控
"人家那套听起来更先进啊。" "先进不好比较，能不能验收好比较。我们整理了一份《数字员工可验收标准》，三层模型：确定性底座、决策质量、业务结果，每层有指标、有算法口径、有验收方式、有数据门槛。您拿着这份清单去比任何一家——包括我们自己，谁的数是真的、谁的数是形容词，一目了然。" 把客户变成裁判，我们就赢了
"那你们凭什么说你们准？" "三条真东西：一，PS 转炉造渣终点判断准确率 96.0%，江铜贵溪 5 号炉在用；二，四大平衡黄金回归 75/75，误差 0.0002%，随时可复跑；三，您厂自己的数据可以做影子模式试跑。剩下那些我们没有真实数据的指标，我们在白皮书里明写'待采集'——我们不拿形容词当指标。" 主动承认"哪些还没有数据"，是我们最强的信任建设工具
"那假别人也在他们的材料里抄你们的验收条款怎么办？" "那更好。验收标准一旦成为行业默认门槛，最早定义它的人天然占优——因为我们的白皮书是照着我们自己的架构写的，每一条我们都做得到。别人要么照抄承认跟随，要么改条款然后解释为什么。" 内部话术，不对客户说
"你们会不会也不给看数据，光给 PPT？" "可以现场复跑。黄金回归脚本在这儿，Python 跑一遍，JS 移植版本再跑一遍，结果对不上我们从头查。演示态和生产态我们分开给您讲，什么是生产真跑出来的、什么是还在采集的，我们不混。" 承诺"可复跑"是高信任低成本动作

6.2 应答三句话模板（记不住就用这个）

① 认——"这个方向是对的，大家做的是同一件事。"（不树敌）
② 转——"差别在于：角色是视图还是智能体；数字能不能验收。"（升维）
③ 落——"要不这样，我们把验收条款摊开来对照一下？谁达标谁说话。"（拿到主动权）
