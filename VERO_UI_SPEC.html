结论三条裁决（结论先行）

路线收敛
仓库三套界面收敛为一，以 VERO_MVP.html 的暖色机理风为准，废弃 frontend/ 暗色霓虹。
信息架构
按「炉长 / 工艺 / 数据」三层角色视图分层，把专家级证据从炉长驾驶舱剥离。
风格方向
从「消费级 SaaS 科技感」转向「工业 HMI 可读性 + 证据报告严谨感」，只保留 红/黄/绿 三态语义。

01现状诊断：三套界面，两条路线

问题根因不是"风格旧"，而是仓库里残留着**两条互相冲突的产品路线**。先裁决路线，风格自然落定。

界面定位视觉与产品定义 v1.0 的关系
web/最早 vanilla 原型浅色朴素已淘汰
frontend/（React）「VAgent v7.0」全程版：L1 配料 + L2 动态 + 枪位 + AI Copilot 聊天暗色霓虹 + 多智能体卡片冲突 产品定义已定"无聊天框、不碰事中、只开吹前"
VERO_MVP.html当前交付 MVP v0.2「配吃助手（开吹前）」暖色纸张 + 熔融橙 + 钢蓝，编号面板 + 证据卡完全对齐
两处硬伤（frontend/ 必须处理）：① 外链 Google 头像 lh3.googleusercontent.com 违反 A6「离线、数据不出厂」；② 「AI Copilot / 协调中枢 / 安全护栏」多智能体暗示「AI 炉长」，踩品牌禁用词红线。
